# **# Функционал приложения**

Приложение позволяет шифровать и расшифровывать текст с использованием шифра Цезаря. Программа поддерживает несколько режимов работы, обеспечивает обработку больших файлов и имеет функцию проверки входных данных.

## **Основные задачи:**

Реализация шифра Цезаря:
- Создание и использование алфавита.
- Алгоритм сдвига символов в соответствии с заданным ключом.

## **Обработка файлов:**
- Функционал для работы с файлами (чтение, запись).

## **Валидация входных данных:**
- Проверка существования файлов.
- Допустимость ключей.
